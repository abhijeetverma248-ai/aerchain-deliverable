# Recorded Walkthrough Script (5–7 min)
1. **Problem (30s):** “I chose corrugated packaging and deliberately made five supplier responses messy.”
2. **RFx (45s):** Show scope → AI RFx draft. Explain outbound supplier channel is stubbed.
3. **Intake (90s):** Upload Excel, Word, PDF, photo, email. Run live extraction.
4. **Ugly edges (60s):** Point out USD, missing lines, quality failure, confidence/evidence.
5. **Analyst (90s):** Ask: “Among quality-passing vendors, who is cheapest per line, and where do missing quotes/currency prevent certainty?”
6. **Trust (45s):** Explain missing ≠ zero, currency preserved, eligibility separate, evidence retained.
7. **Close (30s):** Explain deliberate omissions and the core thesis: messy response → normalized data → defensible decision.
